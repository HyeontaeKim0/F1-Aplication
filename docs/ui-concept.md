# UI 구상 (1차 범위)

작성: 2026-11-19 / 상태: 구상 초안. 구현 코드, 라우트, 폴더 구조는 포함하지 않는다(화면은 이름으로만 지칭).

범위: 홈, 일정, 레이스 결과, 순위, 드라이버 목록/상세, 팀 목록/상세. 라이브, 게시판, 뉴스, 영상은 제외.
참고 사이트는 "다음 레이스 히어로 + 표/카드 중심의 정보 밀도"라는 분위기만 참고한다.

## 1. 디자인 방향

### 컨셉: 타이밍 타워

F1 중계 화면의 타이밍 타워(순위, 팀 색 눈금, 3글자 코드, 우측 정렬 갭)를 앱의 표 한 줄로 쓴다. 결과표와 드라이버/팀 순위표가 모두 이 "타이밍 행"이 되고, 이 행이 앱에서 가장 눈에 띄는 요소다. 그 밖의 요소(내비게이션, 카드, 헤더)는 조용하게 둔다.

- 한국어 우선. 숫자(순위, 포인트, 기록, 갭)는 고정폭 숫자로 정렬한다.
- 카드는 "대상 소개"(드라이버, 팀, GP 목록)에만 쓰고, 순위/결과 데이터는 카드로 나누지 않고 표로 둔다.

### 다크/라이트

- 다크 우선으로 설계한다(결정). 라이트는 같은 토큰 이름의 대응 값으로 제공하고, 기본은 시스템 설정을 따른다.
- 두 테마 모두 토큰으로만 색을 지정한다(컴포넌트에 hex 직접 사용 금지).

### 색 토큰

순검정과 단색 레드 조합 대신, 푸른빛 회색 계열 바탕에 호박색(앰버) 한 가지를 "현재/다음" 표시에만 쓴다. 값은 초안이며 구현 전에 대비를 검증한다.

| 토큰                 | 용도                              | 다크              | 라이트            |
| -------------------- | --------------------------------- | ----------------- | ----------------- |
| `bg`                 | 페이지 배경                       | #10151c           | #eef1f5           |
| `board`              | 표, 카드 배경                     | #171e28           | #ffffff           |
| `board-2`            | 호버, 표 헤더 행                  | #202a37           | #e3e8ee           |
| `line`               | 행 구분선, 테두리                 | #2c3847           | #cfd6df           |
| `text` / `text-mute` | 본문 / 보조                       | #e8edf3 / #8d9bad | #121821 / #566274 |
| `signal`             | 다음 레이스, 현재 선택, 최신 결과 | #ffb703           | #b36b00           |
| `positive`           | 순위 상승, 완료                   | #3ddc97           | #0f8a5a           |
| `danger`             | 취소, DSQ, 오류                   | #ff6b6b           | #c62f2f           |

- `signal`은 한 화면에 한두 곳만 쓴다(강조의 희소성 유지). 레드는 `danger`에만 쓴다.
- 상태색은 항상 아이콘과 라벨을 함께 쓴다.
- 대비는 본문 4.5:1, 비텍스트 3:1 이상을 목표로 한다.

### 팀 색상 활용 방식

- 데이터의 `team_colour`(hex, 시즌마다 변경 가능)를 런타임에 **보조 장식**으로만 쓴다.
  - 허용: 타이밍 행 왼쪽 3px 눈금, 팀 칩의 점, 상세 화면 헤더의 얇은 띠.
  - 금지: 텍스트 색, 정보 전달의 유일 수단.
- 팀 색 위에는 텍스트를 올리지 않는다.
- 팀 색이 없거나 배경과 대비 3:1 미만이면 `text-mute` 중립색으로 대체한다. 판정은 한 곳에서 처리한다.

### 타이밍 행 (핵심 컴포넌트 스펙)

```
 순위  눈금 코드   이름(md+)           갭/기록       포인트
  1   ▌   VER   Max Verstappen    1:32:45.456     25
  2   ▌   NOR   Lando Norris         +3.204       18
 10   ▌   ALO   Fernando Alonso    +1랩            1
  -   ▌   HUL   Nico Hulkenberg     DNF            0
```

- 높이 44px(터치 대상 기준). 행은 모서리 없이 `line` 헤어라인으로만 구분하고, 표 컨테이너만 작은 모서리(4)를 쓴다.
- 순위 칸은 우측 정렬 고정폭 숫자, 코드는 굵은 폭 좁은 서체에 자간 약간.
- 갭/기록과 포인트는 우측 정렬 고정폭 숫자. 1위는 총 기록, 나머지는 `+초`.
- 1위 행만 `board-2` 배경. 포디엄(2, 3위) 강조는 두지 않는다.
- DNF/DNS/DSQ는 순위 칸 "-" + 갭 칸에 텍스트 배지로 표시하고 표 하단에 모은다.
- 링크 행(드라이버 상세 이동)은 행 전체가 클릭 영역이고 포커스 링은 `signal` 2px.

### 타이포

- 한글 본문: 시스템 한글 산세리프 또는 Pretendard(웹폰트는 열린 질문 8번). 최종 선택 전까지는 시스템 폰트로 설계한다.
- 코드/숫자: 폭이 좁은 산세리프(예: `next/font/google`의 Barlow Condensed 같은 계열, 후보 단계). 이미 있는 `next/font` 사용이라 npm 의존성은 늘지 않는다.
- 숫자는 `tabular-nums`. 드라이버 약어는 대문자 3글자, 자간 +0.04em.
- 스케일(모바일 / 데스크톱): 화면 제목 24 / 32, 섹션 제목 18 / 20, 본문 14 / 16, 캡션 12. 위계는 굵기와 크기로 만들고, 대문자 라벨이나 장식용 소제목은 쓰지 않는다.
- 본문 한 줄 길이는 80자 이내.

### 간격, 모서리, 모션

- 간격은 4px 단위 스케일(4, 8, 12, 16, 24, 32, 48). 데이터 표는 촘촘하게, 카드와 섹션 사이는 넉넉하게.
- 모서리: 표 컨테이너 4, 대상 소개 카드 8, 배지는 전체 둥글게. 모든 요소에 같은 반경을 쓰지 않는다.
- 그림자는 쓰지 않고 `line`과 `board` 단차로 구분한다.
- 모션은 사용자 동작에 반응하는 것(탭 전환, 시즌 선택 열림)만 둔다. 진입 애니메이션은 두지 않는다. `prefers-reduced-motion`을 존중한다.

## 2. 공통 요소

### 내비게이션

- 항목: 홈, 일정, 결과, 순위, 드라이버, 팀. (6개)
- 모바일: 상단에 로고 + 시즌 선택, 하단 고정 탭바(5개: 홈/일정/순위/드라이버/팀). 결과는 일정에서 진입하고 순위 화면 안에도 최신 결과 링크를 둔다.
- 데스크톱(lg 이상): 상단 가로 내비게이션 한 줄. 현재 화면은 `aria-current`와 밑줄로 표시.
- 하단 탭바는 안전 영역(safe area) 패딩을 포함한다.

### 시즌 선택

- 현재 보는 시즌(연도)을 헤더에 항상 노출하는 작은 드롭다운(데이터 범위 2023~현재).
- 시즌을 바꾸면 현재 화면 종류는 유지한 채 해당 연도로 이동한다. 상세 화면(드라이버/팀/결과)에서 해당 시즌에 대상이 없으면 목록 화면으로 보낸다.
- 키보드로 열고 닫을 수 있고, 모바일에서는 바텀시트 형태를 쓸 수 있다.

### 모바일 우선 레이아웃

| 구간 | 폭    | 레이아웃                                          |
| ---- | ----- | ------------------------------------------------- |
| 기본 | ~639  | 1열, 좌우 여백 16, 하단 탭바                      |
| `sm` | 640+  | 카드 2열 가능                                     |
| `md` | 768+  | 카드 2~3열, 표에 보조 열 노출                     |
| `lg` | 1024+ | 상단 내비게이션, 최대 폭 1200 중앙 정렬, 2단 구성 |
| `xl` | 1280+ | 카드 4열(드라이버/팀 목록)                        |

- 표는 모바일에서 핵심 열만(순위, 이름, 팀 막대, 기록/포인트) 보여주고, 보조 열(랩 수, 포인트 등)은 `md`부터 노출한다. 가로 스크롤은 피한다.

### 공통 상태 패턴

- 로딩: 실제 레이아웃과 같은 크기의 스켈레톤(표는 행 수만큼). 깜빡임 방지를 위해 최소 표시 시간은 두지 않는다.
- 오류: 카드형 메시지 + "다시 시도" 버튼. 레이트 리밋(429)은 "잠시 후 다시 시도해주세요"로 구분한다.
- 빈 상태: 이유 문장 + 다음 행동 링크(예: 다른 시즌 선택).

## 3. 화면별 구성

표기: `[ ]` 버튼/선택, `▮` 팀 색 막대, `( )` 배지.

### 3.1 홈

핵심: "다음 레이스 히어로"(세션 타임라인), 최신 결과 요약(상위 3~5), 순위 요약(드라이버/팀 상위 5), 바로가기.

```
모바일                              데스크톱(lg)
┌──────────────────────┐            ┌──────────────────────────────────────┐
│ F1  2026 [v]         │            │ F1  홈 일정 결과 순위 드라이버 팀 [2026v]│
├──────────────────────┤            ├────────────────────┬─────────────────┤
│ 다음 레이스          │            │ 다음 레이스 히어로 │ 최신 결과        │
│ 라스베이거스 GP      │            │ 서킷 이미지 + 국기 │ 1 ▮ VER  1:32.4 │
│ [서킷 이미지]        │            │ 11/22 (일) 13:00   │ 2 ▮ NOR  +3.2   │
│ 11/22 (일) 13:00 KST │            │ D-3일 02:11        │ 3 ▮ LEC  +5.8   │
│ D-3일                │            │ [일정 보기]        │ [전체 결과]      │
├──────────────────────┤            ├────────────────────┼─────────────────┤
│ 최신 결과  [전체 >]  │            │ 드라이버 순위 TOP5 │ 팀 순위 TOP5    │
│ 1 ▮ VER   1:32.456   │            │ 1 ▮ NOR  410       │ 1 ▮ McLaren 800 │
│ 2 ▮ NOR   +3.2s      │            │ ...                │ ...             │
│ 3 ▮ LEC   +5.8s      │            │ [전체 순위]        │ [전체 순위]     │
├──────────────────────┤            └────────────────────┴─────────────────┘
│ 드라이버 순위 TOP5   │
│ 팀 순위 TOP5         │
├──────────────────────┤
│ [홈][일정][순위][드][팀]│
└──────────────────────┘
```

- 히어로는 큰 카운트다운 대신 레이스 주간 세션(연습, 예선, 레이스)을 시간 순 타임라인으로 보여주고, 다음 세션만 `signal`로 표시한다. 남은 시간은 그 옆 보조 텍스트로 줄인다(열린 질문 9번).
- 최신 결과와 순위 요약은 타이밍 행(1장)을 그대로 쓴다.
- 카운트다운을 넣는다면 클라이언트 최소 단위로 분리하고, 서버 렌더 시에는 날짜/시간 텍스트를 먼저 보여준다.
- 시즌이 끝났거나 다음 레이스가 없으면 히어로를 "시즌 종료 + 우승자 요약"으로 대체한다.
- 빈 상태: 최신 결과가 없으면(시즌 초반) "아직 진행된 레이스가 없습니다"와 일정 링크.
- 로딩: 섹션별로 독립 스켈레톤. 한 섹션 오류가 다른 섹션을 막지 않는다.

### 3.2 일정

핵심: 그랑프리 카드/리스트, 완료/예정/취소 상태 배지, 다음 레이스 강조, 날짜(KST) 표기.

```
┌──────────────────────────────────┐
│ 2026 시즌 일정          [2026 v] │
│ [전체] [예정] [완료]             │
├──────────────────────────────────┤
│ ▌R22  라스베이거스 GP  (다음)    │  <- signal 테두리로 강조
│ ▌[국기] Las Vegas  11/20-22      │
│ ▌서킷 이미지(md+)                │
├──────────────────────────────────┤
│  R21  브라질 GP        (완료)    │
│  [국기] São Paulo  11/6-8  [결과>]│
├──────────────────────────────────┤
│  R05  ○○ GP            (취소)    │  <- 취소선 + 아이콘, 결과 링크 없음
└──────────────────────────────────┘
```

- 프리시즌 테스트는 목록에서 제외하거나 별도 접힘 그룹으로 분리(열린 질문).
- 상태 배지: 완료(체크 아이콘), 예정(시계), 다음(강조 라벨), 취소(금지 아이콘 + 취소선).
- 날짜는 KST 기본, 현지 시간은 보조 캡션.
- 빈 상태: 해당 시즌 일정이 없으면 "일정 정보가 없습니다" + 다른 시즌 선택.
- 로딩: 카드 스켈레톤 6개. 오류: 재시도 카드.

### 3.3 레이스 결과

핵심: GP 헤더(이름, 국기, 서킷 이미지, 날짜), 세션 탭(레이스/스프린트/예선), 결과표, 상태 표시.

```
┌──────────────────────────────────────┐
│ < 일정   브라질 GP   R21             │
│ [국기] Interlagos  11/6-8  [서킷 img]│
│ [레이스] [스프린트] [예선]           │  <- 해당 GP에 있는 세션만
├──────────────────────────────────────┤
│ 순위 드라이버(팀)         기록/갭 pt │
│  1  ▮ VER Max Verstappen  1:32.4  25 │
│       Red Bull                       │
│  2  ▮ NOR Lando Norris    +3.2s   18 │
│ ...                                  │
│ 18  ▮ ALO ...             (DNF)   0  │
│ 19  ▮ ...                 (DNS)   0  │
│ --  ▮ ...                 (DSQ)   0  │
└──────────────────────────────────────┘
```

- 정렬은 순위 순. DNF/DNS/DSQ는 순위 칸에 "-"와 텍스트 배지(색 + 약어 + 툴팁 "리타이어/출전 안 함/실격")로 표시하고 표 하단에 모은다.
- 갭 형식: 1위는 총 기록, 나머지는 `+초`. 랩 차이는 `+1랩`. `duration`/`gap_to_leader` 형태가 불확실하므로 값이 없으면 "-"로 처리한다.
- 모바일: 순위, 드라이버(약어 + 막대), 기록/갭, 포인트. 풀네임과 팀명은 `md`부터 보조 열 또는 2행 표기.
- 드라이버 행은 드라이버 상세로 연결한다.
- 상태별:
  - 미개최 세션: 표 대신 "예정" 카드(세션 시작 시각).
  - 취소 세션: 취소 배지 + 안내 문구.
  - 데이터 없음/404: "결과가 아직 제공되지 않습니다".
  - 로딩: 헤더 + 표 스켈레톤. 오류: 재시도.

### 3.4 순위

핵심: 드라이버/팀 탭, 순위표(순위, 이름, 팀 막대, 포인트), 기준 시점 표기("브라질 GP 종료 기준").

```
┌──────────────────────────────────────┐
│ 2026 순위     기준: 브라질 GP 종료   │
│ [ 드라이버 | 팀 ]                    │
├──────────────────────────────────────┤
│  1  ▮ NOR  Lando Norris   McLaren 410│
│  2  ▮ VER  Max Verstappen RB      395│
│  3  ▮ PIA  ...            McLaren 360│
│ ...                                  │
│ [최신 레이스 결과 보기 >]            │
└──────────────────────────────────────┘
```

- 포인트 옆에 직전 라운드 대비 순위 변동(▲▼ 아이콘 + 숫자, 색만 쓰지 않음)을 `md`부터 표시한다(`position_start`/`position_current` 활용).
- 팀 탭: 팀 이름, 포인트, 소속 드라이버 약어 2개.
- 탭은 키보드 화살표로 이동 가능한 탭 패턴. 선택 상태는 밑줄 + 굵기.
- 빈 상태: 완료된 레이스가 없으면 "시즌 첫 레이스 이후에 제공됩니다".
- 로딩: 행 스켈레톤 20개. 오류: 재시도.

### 3.5 드라이버 목록 / 상세

**목록**: 카드 그리드(모바일 2열, `md` 3열, `xl` 4열), 팀별 그룹 또는 번호순 전환(기본: 팀별).

```
┌────────┐ ┌────────┐
│▔▔▔▔▔▔▔▔│ │▔▔▔▔▔▔▔▔│  <- 상단 얇은 팀 색 띠
│ [헤드샷]│ │ [이니셜]│  <- 헤드샷 null이면 이니셜 원형
│ 1 VER  │ │ 4 NOR  │
│ Max V. │ │ Lando N│
│ Red Bull│ │ McLaren│
└────────┘ └────────┘
```

- 국적은 `country_code`가 null이라 1차에서 표시하지 않는다(열린 질문).
- 헤드샷 미제공 시 이니셜 + 팀 색 테두리의 플레이스홀더.

**상세**: 프로필 헤더, 시즌 요약(순위, 포인트), 소속 팀 링크. 라운드별 결과는 1차 제외(호출량).

```
┌──────────────────────────────────────┐
│ ▔▔▔▔▔▔ (팀 색 띠)                    │
│ [헤드샷]  #4 Lando Norris            │
│           NOR · McLaren (팀 링크)    │
├──────────────────────────────────────┤
│ 시즌 순위 2위 │ 포인트 410            │
├──────────────────────────────────────┤
│ 팀 동료  ▮ PIA Oscar Piastri         │
└──────────────────────────────────────┘
```

- 상태별: 목록 비어 있음("해당 시즌 드라이버 정보가 없습니다"), 존재하지 않는 드라이버(찾을 수 없음 화면 + 목록 링크), 시즌 순위 미제공(통계 영역을 "-"로), 로딩(카드/헤더 스켈레톤), 오류(재시도).

### 3.6 팀 목록 / 상세

**목록**: 팀 카드(팀 색 띠, 팀명, 소속 드라이버 2명 이니셜/헤드샷, 시즌 순위/포인트).

```
┌──────────────────────────────┐
│▌ McLaren              1위 800│
│▌ [NOR 헤드샷] [PIA 헤드샷]   │
└──────────────────────────────┘
```

**상세**: 팀 헤더(색 띠 + 팀명 + 순위/포인트), 소속 드라이버 카드, 시즌 포인트 요약.

```
┌──────────────────────────────────────┐
│ ▌McLaren  시즌 순위 1위  포인트 800  │
├──────────────────────────────────────┤
│ 드라이버                             │
│ [카드 NOR]   [카드 PIA]              │
└──────────────────────────────────────┘
```

- 팀명이 시즌마다 바뀌므로(예: 2026 Audi) 시즌 단위로 표시하고, 연도 간 연결 표시는 하지 않는다(열린 질문).
- 팀 로고는 데이터에 없으므로 팀 색 + 팀명 텍스트로 정체성을 표현한다.
- 상태별: 목록 비어 있음, 존재하지 않는 팀(찾을 수 없음 화면), 순위 미제공("-"), 로딩, 오류는 드라이버와 동일 패턴.

## 4. 재사용 컴포넌트 후보 (역할만)

- 앱 셸: 상단 바, 하단 탭바, 페이지 컨테이너(최대 폭/여백).
- 시즌 선택기: 연도 드롭다운(클라이언트).
- 섹션 헤더: 제목 + 보조 링크("전체 보기").
- 탭: 드라이버/팀, 세션 종류 전환(접근 가능한 탭 패턴).
- GP 카드/행: 국기, 이름, 날짜, 상태 배지, 강조 변형(다음 레이스).
- 상태 배지: 완료/예정/다음/취소, DNF/DNS/DSQ 공용(아이콘 + 텍스트).
- 팀 색 막대/띠/점: 색 판정(대비 부족 시 중립색 대체)을 포함한 단일 책임 요소.
- 드라이버 식별자: 번호 + 약어 + 이름, 모바일/데스크톱 표기 변형.
- 아바타: 헤드샷 또는 이니셜 대체.
- 결과 표, 순위 표: 반응형 열 노출, 우측 정렬 숫자 셀.
- 순위 변동 표시: 아이콘 + 숫자.
- 카운트다운: 클라이언트 최소 단위.
- 드라이버 카드, 팀 카드: 목록용.
- 통계 타일: 순위, 포인트 등 라벨 + 값.
- 스켈레톤: 표, 카드, 헤더 변형.
- 상태 메시지: 빈/오류/찾을 수 없음 공용(제목, 설명, 행동 버튼).
- 이미지 래퍼: 서킷 이미지, 국기, 헤드샷의 크기/대체 처리.

## 5. 접근성

- 팀 색만으로 구분하지 않는다. 항상 이름 또는 약어 텍스트를 함께 둔다. 색은 보조 장식.
- 상태(DNF/DNS/DSQ, 취소, 순위 변동)는 색 + 아이콘 + 텍스트 3중 표기. 약어에는 `abbr`/툴팁/스크린리더 전체 문구 제공.
- 텍스트 대비 4.5:1 이상, 비텍스트(테두리, 막대) 3:1 이상. 다크/라이트 모두 검증.
- 시맨틱 표(`table`, `th scope`, 캡션)를 사용하고, 모바일에서 열을 숨겨도 의미는 유지한다.
- 키보드: 모든 링크/탭/드롭다운 포커스 가능, 포커스 링은 `signal` 2px 이상, 탭은 화살표 이동.
- 이미지: 국기는 이름 텍스트가 옆에 있으면 `alt=""`, 헤드샷은 이름이 인접하면 장식 처리, 서킷 이미지는 대체 텍스트 제공.
- 카운트다운은 매초 읽히지 않도록 `aria-live`를 쓰지 않고 정적 텍스트(날짜/시간)를 병기.
- 모션은 최소화하고 `prefers-reduced-motion`을 존중한다. 터치 대상은 44px 이상.
- 페이지 언어는 한국어로 선언하고, 영문 고유명사(드라이버/팀)는 그대로 둔다.

## 6. 열린 질문 (사용자 결정 필요)

1. **내비게이션 구성**: 하단 탭바 5개 + 결과는 일정에서 진입하는 안으로 괜찮은가? 결과를 독립 탭으로 둘 것인가?
2. **기본 테마**: ~~다크 우선~~ 확정(다크 우선, 라이트는 시스템 설정 연동). 남은 질문: 사용자 토글을 둘지.
3. **한글화 범위**: GP/국가/팀명 한글 매핑 vs 영문 유지(드라이버 이름은 영문 유지 가정). 화면 폭과 정렬에 영향.
4. **프리시즌 테스트 처리**: 일정에서 제외 vs 접힘 그룹으로 표시.
5. **드라이버 국적**: 1차 제외(기본 가정) vs 별도 매핑 데이터 도입.
6. **시간 표기**: KST 단독 vs 현지 시간 병기(기본 가정: KST 본문 + 현지 보조).
7. **팀 정체성**: 팀 로고 없이 색 + 텍스트로 충분한가? 팀 이름이 바뀐 시즌의 연결 표시를 할 것인가?
8. **폰트**: 시스템 폰트만 쓸지, 한글 웹폰트(예: Pretendard)나 아이콘 세트 도입을 허용할지. 새 의존성/리소스 추가에 해당하므로 승인 필요.
9. **카운트다운 등 클라이언트 요소**: 홈 히어로의 실시간 카운트다운을 넣을 것인가, 정적 "D-N일"만 쓸 것인가.
10. **라운드별 결과**: 드라이버/팀 상세에서 1차 제외(plan 권장)로 확정하는가?
